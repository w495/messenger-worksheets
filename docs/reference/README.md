# Справочники

Точный синтаксис команд, параметры конфигурации, лимиты и интерфейсы.
Используйте этот раздел, когда нужно уточнить конкретное значение
или поведение сервиса.

## Оглавление

- [Команды чата](commands.md) — аргументы команд, выбор модели,
  управление задачей и комментарии для участников.
- [Конфигурация и лимиты](configuration.md) — файл установки,
  переменные окружения, ограничения запросов и истории.
- [Службы, каталоги и административные команды](services.md) —
  systemd-службы, расположение файлов и операции `worksheet-admin`.
- [API и протокол пользовательского клиента](messenger-user-client.md) —
  подключение, чтение, запись, файлы и подтверждение операций.
