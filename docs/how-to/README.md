# Практические руководства

Инструкции для конкретных задач администратора и разработчика.
Выберите нужный результат; проходить все руководства подряд не требуется.

## Оглавление

- [Установить и запустить сервис](install.md) — подготовить машину,
  настроить два чата и проверить доставку файлов.
- [Обновить, проверить или остановить сервис](operate.md) — обновить код,
  проверить службы, найти причину ошибки или отозвать доступ оператора.
- [Изменить код и выполнить локальные проверки](develop.md) — найти
  нужный модуль, подготовить зависимости и запустить проверки.
