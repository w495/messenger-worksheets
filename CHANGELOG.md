# История изменений

## 2026-11-24

- Добавлены комментарии к сообщениям: строки `#` и `//`, блоки `/* … */`.
  Модель их не получает; сообщения только из комментариев не обрабатываются.
- Убраны имена конкретного аккаунта из кода и документации. Имя Team-бота
  задаётся явно; новый путь токена и имя необязательной аватарки общие.
- В README и руководство добавлен пример работы чата на скриншоте.
- Добавлен независимый пользовательский клиент Мессенджера. Он включён в
  публичный репозиторий и используется по умолчанию; старый клиент необязателен.
- Код опубликован под AGPL-3.0-only. Старый клиент и пользовательские
  изображения в эту публикацию не входят.
- HTTP(S)-ссылки направляются в режим задач с сетью и инструментами.
  Добавлена проверка реального скачивания через worker.
- При ошибке задачи или доставки реакция 👀 заменяется на 💔.
- Исправлены числовые поля `Timestamp`, `Reaction.Type` и `FileInfo.Source`,
  из-за которых сервер отклонял правки, реакции и файлы.
- Исправлена обработка media ID с разделителями `/`. PNG-документы
  загружаются без серверного перекодирования; скачанные bytes проверены.
- Время выполнения задачи увеличено до 1800 секунд, ожидание RPC — до 1860.
  Worker обслуживает до четырёх запросов одновременно.
- Доставка вложения прекращается после пяти неудачных попыток.
  Уже доставленные и окончательно отклонённые файлы удаляются из каталога результатов.
- Для worker-профилей созданы разные CA и TLS-ключи.
- Одновременные запросы с одним UUID не запускают задачу дважды.
  Идентификатор и хеш запроса сохраняются после удаления большого результата.
- Кэш RPC ограничен 256 результатами и 1 ГиБ. Sandbox-worker получил
  ограничения процессов, памяти и CPU; дополнительные каталоги скрыты.
- Версии Python-зависимостей и SHA-256 пакетов закреплены в lock-файле.
- Все Python-функции документированы на русском; наличие docstring проверяется
  перед запуском тестов.
- README и руководство эксплуатации приведены к текущей схеме обработки:
  API-чат использует API key для текста, а задачи обоих чатов — общий Codex worker.

## 2026-11-23

- Подготовлены установщики и systemd-службы для раздельных шлюза и обработчика.
  OAuth Мессенджера и OpenAI API key хранятся в разных конфигурациях.
- Добавлены HTTPS RPC, транспортные токены, проверки worker и восстановление TLS.
  Исправлена совместимость CA с Python 3.14.
- Установщик восстанавливает частично созданный venv и проверяет зависимости
  до запроса секретов.
- Добавлены диагностика OpenAI API и Codex CLI, авторизация через API key
  и административный helper с фиксированным набором команд.
- Подготовлены отдельные профили API, запуска от Linux-пользователя
  и sandbox-admin. Чаты получают раздельные состояния и RPC-токены.
- Обычные текстовые запросы API-чата переведены на прямой Responses API.
  Его файловые задачи направлены в sandbox-admin.
- Sandbox-admin получил доступ к сети и инструментам Codex. Домашний каталог
  оператора ему недоступен.
- Ответы и вложения перенесены в тред исходного сообщения. PNG отправляется
  картинкой и отдельным документом.
- Добавлены редактируемый индикатор выполнения и реакции на исходное сообщение.
  Появились разные наборы кадров; интервал попытки обновления сокращён до 100 мс.
- Исправлено определение timestamp отправленного сообщения и повторное чтение
  истории при задержке появления сообщения на сервере.
- Сообщения собственного аккаунта и удалённые треды исключены из обработки.
  Ошибки worker больше не запускают бесконечную повторную обработку запроса.
- Подготовлен экспериментальный Team Bot API с проверкой имени и организации.
  В основном развёртывании он не используется.
- OAuth client ID вынесен в настройку старого клиента.
  Заголовок организации проверяется перед отправкой.
