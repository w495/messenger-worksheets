# Необязательный старый клиент

Основной клиент находится в `messenger-worksheets/messenger_user_client/`
и включён в публичный репозиторий. Для обычной установки эта директория не нужна.

Режим `WORKSHEET_MESSENGER_BACKEND=legacy` поддерживает отдельно установленный
старый клиент с модулями `client.py` и `transport.py`. Эти файлы в публичный
репозиторий не входят и лицензией AGPL этого проекта не покрываются.

Команды отката проверяют старый клиент до изменения конфигурации и перезапуска.
Если он отсутствует или аккаунт не совпал, работающий шлюз остаётся включённым.
